# 画像認識チェック

公開URL: https://salsnoah.github.io/mj_study/ocr-check.html

スマホのブラウザで画像を選び、拡大した元画像と認識結果を見比べます。手牌と自分の副露のみが比較対象です。学習帳のアプリとは別の入口で、問題・教材・localStorage・OCR補正見本を読み書きしません。画像は外部送信せず、タブ内のメモリで処理します。閉じるかクリアすると結果は消えます。同梱モデルの取得には通信が必要です。

PNG/JPEG/WebP、20 MiB・2400万画素まで。ブラウザがEXIF方向を適用し、認識時は長辺1920pxへ縮小します。HEICは非対応です。現行OCRは同期処理のため、その計算中は中断操作が反映されるまで短い待ち時間があります。終了後に古い結果を反映しないよう、中断・画像切替を確認します。

認識エンジンは main の `be2d983` 時点の `autoRead` / `inferMeld` と同梱モデルv4を利用します。PR42/43のデータ管理・槓推定変更は含めません。端末追加学習は空に固定しています。加槓・上下の重なりの自動検出は未対応で、同牌4枚が大明槓になる場合があります。要確認表示は正解率ではありません。

正解を元画像から別途入力し、確定してから比較します。予測を正解へ自動コピーしません。副露なしは明示チェックが必要です。空欄は未入力、`-` は確認済みの牌なし、`?` / `back` は正解牌種不明です。画像切替は正解と指標をリセットします。

指標版は `multiset-v1`。手牌は順不同・枚数付き集合で、赤5と通常5は別牌です。槓は物理4牌。副露は画像の左から組を対応させ、組内は順不同、種別を別計算します。牌一致率は共通牌数 / max(既知正解枚数, 予測枚数−正解不明枠数)。不足と余分を減点します。除外できるのは正解不明枠だけで、既知正解に対する予測不明は不一致です。分母0は算出不可。正解不明を含む画像の完全一致は保留です。画像1件の値をデータセット全体の精度とは呼びません。

CSV/JSONには画像名・ハッシュ・寸法・縮小条件、予測、独立して確定した正解、除外数・認識不明数・指標分母、コードcommit、モデルSHA-256、指標版を含みます。画像本体や切り出し画像は含みません。未確定の出力は正解未入力として区別します。Sheetsへ貼る場合もこの区別を保持してください。

再現用確認:

```sh
npm test -- src/ocr-check src/features/import
npm run typecheck
npm run build
npm run dev -- --host 127.0.0.1 --port 5177
# 別ターミナル（Playwright Chromiumが必要）
node scripts/validate-ocr-check-ui.mjs
node scripts/validate-ocr-check-engine.mjs
```

UI検証は合成画像と注入した認識結果で、390/1280px、独立正解、赤牌差分、CSV/JSON、取消・連打、破損・過大ファイル、モデル取得失敗、ストレージ不使用を確認します。エンジン検証は本物のブラウザデコードと現行OCRでEXIF6・縮小・画素上限・空画像・未対応形式・中断・白画像未検出を確認します。実雀魂100枚の精度評価や実機iPhone試験ではありません。
