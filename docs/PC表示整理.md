# PC表示の整理

幅1100px以上だけをPC用の配置に切り替える。スマホ版の入力順、初期値、正解表示、残枚数、出題フィルタは維持する。

- 作成は右側で対局条件→牌姿→全37牌を一続きに入力する。左側には受入れと任意の解説・メモを置き、追加タブや説明は増やさない。入力牌の過度な拡大を防ぎ、補足内容を開閉しても未保存値を保持する。
- 学習帳は検索と並べ替えを同じ行に置き、カードを2列、幅1600px以上では3列に並べる。絞り込みは既存の折り畳みを使う。
- PCではナビを上部へ置き、本文の過度な横伸びを抑える。テストの主要操作は適切な幅と位置に保つ。1100px未満では従来の下部ナビ・縦並びへ戻す。

`validate-ukeire-ui.mjs` は320/375/390px等のスマホ回帰を検証する。その試験で作った合成問題のみを `validate-desktop-ui.mjs` の独立ブラウザプロファイルへ読み込み、1280/1440/1920px、1100/1099px境界、低い高さ、150%文字で画像・はみ出し・操作ボタンの重なり・状態保持を確認する。実端末のOSキーボード操作の検証とは区別する。

PCはDOM読み順も左補助→右問題、スマホは問題→補助に揃える。キー付きペインの移動で未保存入力を保持する。点数の3桁＋00と最小シャンテン内の受入れ順位は、本人の追加依頼によるPC/スマホ共通変更。

実行環境置換後、公開PR4と初期PC版はGit tree一致で復旧した。後続変更は新しい候補として再構築している。過去の未公開版bd838402のtree一致は未確認であり、過去の合格結果を今回の候補へ転用しない。CI実画像と3役の同版最終評価は外部反映の再開承認後に行う。
