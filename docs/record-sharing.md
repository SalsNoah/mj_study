# 記録画像の共有

記録帳の「Xに記録を投稿」から、日付・今日と累計のテスト／確認／教材学習回数を確認できます。画像と投稿文は、画面を開いた時点の同じ集計から作成します。累計はグラフの表示期間より前も含め、その端末の今日までの記録を使います。問題名、教材名、コメント、私用メモ、画像添付、正答率や称号を送信内容に含めません。記録は変更しません。

対応する端末では、作成済みの PNG ファイルと文面を Web Share API に渡し、利用者が共有先を選びます。共有先に X が出るか、画像と文面の両方を受け取れるかは端末・共有先アプリによります。API の正常終了を投稿完了とは扱いません。

共有に非対応の場合やうまく受け渡せない場合は、「画像を保存」→「Xの投稿画面を開く」で進みます。X の投稿画面には文面を渡し、利用者が保存画像を添付します。画像は自動添付されません。キャンセルやエラーの後に自動で画像を保存したり、別画面を開いたりしません。投稿自体は利用者が X で確認・確定します。

## 参照した一次資料

- [Web Share API — W3C](https://www.w3.org/TR/web-share/): ファイル共有、機能検出、利用者操作に基づく呼び出し、共有先を端末が提供する仕組み。
- [The User Activation API — WebKit](https://webkit.org/blog/13862/the-user-activation-api/): 共有操作に必要な一時的な利用者操作の扱い。画像は共有ボタンを押す前に生成します。
- [X のポストボタン — X ヘルプ](https://help.x.com/en/using-x/add-x-share-button): 文面・リンクを用意した投稿画面から、利用者が編集・投稿する仕組み。ローカル画像を Web Intent で自動添付する方法は確認できていません。

## 検証範囲

集計・タイムゾーン・画像描画と、共有 API の成功／キャンセル／エラーを分けて試験します。CI は合成データだけを使い、実際の PNG を生成・保存して描画を確認します。共有 API はテスト用実装に置換し、X へのリンク先は通信前に遮断して検査します。実際の OS 共有画面、X アプリでの画像・文面受領、投稿完了は CI の合格範囲に含みません。
