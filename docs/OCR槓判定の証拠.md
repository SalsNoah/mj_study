# OCR槓判定の証拠と保留

画像の初回OCRを実行できない環境でも検証できる、判定ロジックの修正。基点はmain `be2d983`。データ準備PR #42とは別で、実画像・モデル見本・学習データを追加しない。実画像の認識精度が向上したという結果ではない。

## 変更

`TileCell` と `MeldCell` に任意の `meldEvidence` を追加した。牌ラベルや確信度と独立して、表／裏／未知、縦／横／未知、重なりなし／未知／上下ペアを保持する。上下ペアは安定した文字列IDとlower/upperを用い、配列の削除で指し先がずれない。ラベルを修正しただけでは未知の形状が確定したことにならない。

現在の `segmentMelds` は列の明るい部分の高さから縦横を推定するだけで、上下重なりや裏牌を検出しない。その結果を受け取る `autoRead` は、向きだけを記録し、face/stackは明示的にunknownとする。未知をnoneと置き換えない。既存の特徴量、モデルバージョン、保存する問題のschemaは変えない。

加槓は同牌種4枚、表向き4枚、同一IDの横向きlower/upperが1組、他2枚は縦向き・重なりなし、赤牌枚数が妥当、という証拠が揃うときだけ返す。戻り値は既存のドメイン形式に合わせ、元のポン3枚を画像順に置き、追加牌を配列末尾へ置く。`calledIndex` と `addedIndex` は元のポンの重ね位置で、追加牌の配列indexではない。赤が元のポン／追加牌のどちらにあるかを維持する。

大明槓は、4枚とも表向き・重なりなしを確認でき、横向きがちょうど1枚の場合だけ返す。同牌4枚や横向きフラグだけでは、暗槓・加槓との区別を確定しない。現行検出器ではこの証拠が揃わないため、以前は大明槓と決め打ちしたケースも確認待ちになる。単に全牌を確定扱いにしても、誤った大明槓を作成画面へ渡さない。4枚・横向き1枚・同牌種の候補には「重なりなし・横向き1枚の大明槓と確認」操作を表示し、利用者が元画像を確認したときだけmanualConfirmationとして明示的に確定できる。既知の積み牌や裏牌の証拠はこの操作で上書きしない。それ以外の曖昧な槓は作成画面で副露を手入力する必要がある。

暗槓は両端の裏牌と中央2枚の一致が必要。一方の中央牌が不明なとき、もう一方から補完しない。五の暗槓で赤牌が見えず、裏牌の赤／通常が分からない場合も確定しない。現行同梱モデルにはback見本がなく、今回の変更が実スクショの裏牌検出を実現するわけではない。

1〜2枚の手牌は、確かな4組の副露、鳴き方向、手牌と副露を合わせた同牌・赤牌枚数の整合が取れる場合だけ従来の一律棄却を解除する。0枚・3枚、3組以下／5組以上、曖昧な槓、低確信度は解除しない。4〜14枚の既存判定は維持する。`locateHand` の帯検出には画面幅の条件があるため、実際に1〜2枚の手牌を発見できるかは実画像で別途確認が必要。

## 検証範囲

人工の牌・形状fixtureで、左／対面／右からの加槓、赤追加牌／赤鳴き牌、証拠不足・矛盾・ペア欠損、複数副露の分割、低枚数手牌の限定救済を検査する。DOM試験はmockした認識結果を用い、曖昧な4枚の自動下書き阻止、利用者の明示確認による大明槓の救済、証拠付き加槓の下書き引継ぎを確認する。画像の検出・切出し精度の試験ではない。

```sh
npm test -- src/features/import src/domain/melds.test.ts src/domain/tileSupply.test.ts src/components/HandView.test.tsx src/components/TileLimit.test.tsx
npm run typecheck
MAHJONG_CHROMIUM=/usr/bin/chromium node scripts/validate-ocr-kan-ui.mjs
```

ブラウザ操作の前に `npm run dev -- --host 127.0.0.1 --port 5177` を起動する。必要なら `MAHJONG_TEST_ORIGIN` を指定する。ブラウザ試験も人工OCR結果を注入し、実画像精度を測らない。

実行結果：既存OCR19件を含む関連81件・型チェック・production buildが成功。独立レビューで指摘された「曖昧な槓から進めない」問題には明示確認を追加し、レビュー担当も関連47件・型チェックを再実行して解消を確認した。インストール済みChromiumで幅390／1280の拒否→明示確認→作成画面への引継ぎが成功した。Playwright付属ブラウザのダウンロードは403で失敗したため、追加取得や迂回はせず既存ブラウザを使用した。

確認用Sheetsの `visual_ai_provisional` と本アプリの `app_ocr_initial` は別の出力。本変更でSheets上の画像にOCRを実行したことにはならない。Sheetsへの書込み、本人訂正・コメントの変更も行わない。
