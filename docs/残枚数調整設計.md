# 残枚数の手動調整

2026-10-04。自動計算された残枚数を、解析画面内で牌ごとに手動調整できるようにする。

- 34種の残数を全打牌候補で共用。赤五と通常五は五の合計として1欄。
- 自動理論残枚数を初期値・上限とし、0〜上限の整数だけを手動設定できる。上限を増やして架空の5枚目を作らない。
- 数値入力、1枚減/増、1種を自動へ戻す、全部を自動へ戻す操作。自動/手動を文字で表示。受け入れの各牌にも手動表示を付ける。
- 無効な編集中の入力は不適用。理由と「集計は前の有効値」を明記する。空欄・負数・小数・指数・文字・上限超えは拒否し、黙って丸めない。リセットは未反映の入力も消す。
- シャンテンと形上有効牌集合はそのまま。残り0枚は別表示し、受け入れ種類数には残り1枚以上だけを含める。全候補の種類数/枚数を同時に更新する。調整数を実山残数や確率と扱わない。
- 解析画面内のみ。保存・共有形式を変えない。牌姿/ツモ/副露/ドラまたは問題IDが変わると、旧局面の手動値はすべて自動へ戻す。Reactのsession keyで同期的に切り替え、effectによる旧値の一瞬の持越しを避ける。牌の順序だけ、タイトル等、同局面の再描画/開閉は保持する。画面移動でも解除されると調整欄の近くに説明する。
- 作成/詳細/テスト回答後で共通。回答前には調整欄も解析も出さない。

## 受入

0/上限/上限0、無効入力と最後の有効値、1種/全リセット、赤通常、打牌後も既知数維持、全候補共通、入力/シャンテン不変、局面変更時の解除、タイトルだけの変更時保持、同牌姿の別問題へ移る時の解除、保存/共有への混入なし、回答前非表示を確認する。既存43計算＋3UIも回帰する。

実ブラウザの描画・狭幅は未確認。DOM結合試験と独立レビューを行い、ブラウザ確認スクリプトは対応環境で実行する。新しい依存は追加しない。
