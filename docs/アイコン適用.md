# 承認済みアイコンの適用

罫線入りノートに一筒を描いた承認済み1254×1254 PNGを採用。再生成・描き直し・切り抜きは行わず、縦横比を維持したLanczos縮小だけを使用する。元画像のSHA-256: `f22177f490cc5aeb58d79a4a2310469d7d75f74936bdf07b2b9c9bd5d86593e0`。

- ブラウザfavicon: 16×16 / 32×32 / 192×192 PNG
- PWA: 192×192、512×512 PNG
- Apple touch: 180×180 PNG
- 旧未使用SVG faviconは削除

512pxは背景まで不透明のため、any/maskableの両方に使用する。中心の一筒の図柄を重要部分として、丸いマスク・角丸表示・中心40%半径のsafe zoneと、小さい表示をCIで視認確認する。OS固有のホーム画面の描画・アイコンキャッシュ更新時期まで自動試験で保証するものではない。

参考: [Web Application Manifest の icon masks](https://www.w3.org/TR/appmanifest/#icon-masks)
