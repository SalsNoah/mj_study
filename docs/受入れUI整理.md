# 受入れ表示と残枚数ボタンの整理

2026-10-04。受入れ周辺の説明を減らし、残枚数の調整入口を移動する変更。

## 変更

- 作成の「全消去」のすぐ右に「残枚数」ボタン。直下の調整欄を開閉する。未完成・不正な入力では無効。
- 受入れは打牌、シャンテン、種類数・枚数、有効牌と残数に絞る。詳しい説明、理論/調整後ラベル、各有効牌の手動注記を省く。
- 「テンパイ（0）」は「テンパイ」、「完成形（−1）」は「完成形」。0枚の有効牌は牌画像と「0枚」で表示し、種類数に含めない。
- 詳細・テスト回答後にも「残枚数」ボタン。回答前には表示しない。
- 計算・保存・共有・4枚上限の仕様は変更しない。手動値は開閉・理牌で保ち、局面や問題の変更で自動へ戻る。
- 入力エラー・上限・自動/手動の短い操作ラベルは調整欄に残す。説明が必要な計算上の制約は設計文書に維持する。
- リリース時の古い表示を避けるため、Service Workerのキャッシュ名をv19へ更新。

## 残る確認

実ブラウザ試験は未完了。実行環境のChromiumはsocket権限制限で起動できず、クラウドブラウザからのlocalhostも接続できなかった。CSS指定とDOM試験を、狭幅の実描画合格として扱わない。

対応環境で開発サーバーを5176番に起動して、次を実行する。

```sh
npm run dev -- --host 127.0.0.1 --port 5176
node scripts/validate-ukeire-ui.mjs
```

既存Chromiumを使う場合は `MAHJONG_CHROMIUM_EXECUTABLE` を指定。別ポートでは `MAHJONG_TEST_ORIGIN` も指定する。新規一時プロファイルと合成牌だけを使い、対象localhost以外への通信を遮断する。検証出力はGit管理外の `evidence/ukeire/`。
