## 動作

- 個別問題のボタンは「確認した（問題一覧に戻る）」。確認の保存に成功した時だけ一覧へ移動する。確認回数・日時・日次件数の既存記録を維持し、テスト回答や教材記録は作らない。
- 一覧で従来の5秒間の取り消しを提供。確認保存後のrevisionと期限を検証し、二重クリック・ブラウザ履歴経由で同じ取消を再実行しない。保存失敗時は元画面・データを保持して再試行可能。取消は確認した日の件数を戻し、日付をまたいでも別日の集計を変更しない。
- スマホ（1099px以下）は下部ナビ直上に固定。ナビと固定領域の実高をResizeObserverで測り、safe area・文字拡大で重ならず本文末尾も隠れない余白を確保。失敗メッセージは固定領域内のrole=alert。PCは上部ナビに合わせて本文内の従来位置。ボタンは全画面幅で1個のみ。
- 新規作成の明示保存は一覧へ。既存問題編集の保存先は従来の詳細のまま。未保存ガードの「保存して移動」はユーザーが選んだ移動先を維持。保存lockを維持し二重登録しない。
- 一覧の検索・牌姿・タグ条件は画面固有stateであり、再入場時に初期化される既存仕様を維持。新規問題が以前の絞り込みで隠れない。教材・複製・テスト回答の遷移は変更しない。
