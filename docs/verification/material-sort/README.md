# 学習教材一覧の並び替え

基点main: `9b4cf41a9ff04827ab85b07c006ab893081b7ea5`（PR36）。今回の並び替えは独立Draft PR。公開承認は未取得。

- 更新日・学習回数・最終学習日の3基準×昇順/降順。既定は更新日の新しい順。
- 最終学習日がない教材は昇降どちらでも末尾。回数昇順では0回が先頭。同値は保存配列順を保つ。日時は数値比較、学習回数は重複イベントIDを除いて集計。
- 表示だけを変更し、保存順・updatedAt・学習回数・コメント・履歴を書き換えない。検索・アーカイブ表示にも同じ基準を適用。
- 学習/アーカイブ/復元によってカードがクリック直下から移動することを防ぐ。基準/昇降の変更または「並べ直す」で最新順へ更新。新規登録成功時も選択中の順序に再配置するため、常に先頭とは限らない。
- 選択はこの一覧画面を開いている間だけ保持。詳細から戻った場合や再読込時は既定順。永続設定は追加しない。
