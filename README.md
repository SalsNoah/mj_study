# 麻雀学習帳

スマホ優先の麻雀学習帳です。牌姿・解説・メモをブラウザの localStorage に保存し、牌の形で検索・クイズ復習・URL共有できます。**ログイン・サーバー保存はありません。**

> **DECKSHOT とは無関係の独立リポジトリです。**

## 最初のコマンド

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5174 を開きます。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー（5174） |
| `npm test` | ユニットテスト（Vitest） |
| `npm run typecheck` | TypeScript 検査 |
| `npm run build` | 本番ビルド → `dist/` |
| `npm run preview` | ビルド結果のプレビュー |

## 使い方（概要）

1. **作成**: 下部ナビ「作成」→ 牌パレットで手牌／ツモ／副露／ドラ表示牌を入力 → 保存
2. **学習帳**: 文字検索と牌姿検索（色替え・反転・数字のずれ）で絞り込み
3. **詳細**: 「確認した」でのみ確認回数+1。PNG保存・URL共有
4. **復習**: 正解あり／なし両対応。苦手優先・タグ・ランダム
5. **設定**: JSONバックアップ／復元、サンプル追加、全件削除

## 打牌別の受け入れと残枚数

作成・詳細・テスト回答後の「受入れ」で、各牌を切った後のシャンテン、進む牌の種類と残枚数を確認できます。通常形・七対子・国士を対象にした四麻34種の計算です。13枚相当では現在の受け入れを表示します。打牌候補は打牌後シャンテンが最小の候補だけを受入れ枚数順に最大3件表示し、「すべて表示」で全件を確認できます。各候補のシャンテンも確認してください。

作成では「全消去」の右にある「残枚数」を押し、萬子・筒子・索子・字牌から牌を選んで共通の入力欄で0〜自動計算の上限まで変更できます。赤五と通常五は合算し、全打牌候補の合計を更新します。詳細・テスト回答後も「残枚数」ボタンから調整できます。調整は画面内だけで、牌姿等の変更や画面移動で自動に戻ります。保存・共有には含まれません。

数値は入力済みの手牌・ツモ・副露・ドラ表示牌を除いた上限で、実際の山残数、役・フリテン、最善打牌の判定ではありません。テスト回答前には表示しません。

手牌・鳴き・ドラ表示牌を合わせて同じ牌が5枚以上にならないよう、追加できない牌は入力段階で無効化します。赤五は通常五と合算し、鳴きは組全体の枚数で確認します。読み取り結果の修正でも同じ上限を使い、不正な既存入力は自動で消さず修正できるように表示します。

仕様は [受け入れ設計](docs/受け入れ設計.md)、[残枚数調整設計](docs/残枚数調整設計.md)、[入力上限](docs/牌枚数上限修正.md) を参照してください。説明を省いた表示と残枚数ボタンの変更・最新の検証結果は [受入れUI整理](docs/受入れUI整理.md) に記載しています。

スマホ向けのタブ構成・操作導線は [スマホUI整理](docs/スマホUI整理.md) を参照してください。

## ローカル保存の制約

- キー: `mahjong-study:v1`（localStorage）
- 端末・ブラウザ・プロファイルが違えば別の学習帳
- ブラウザのデータ削除で消えます。定期的に設定から JSON バックアップを取ってください
- 目安上限 4MiB（3MiB で注意表示）。画像を増やしすぎないでください

## 共有用静的ホスト

問題データはサーバーに送りません。**アプリ本体だけ**を静的配信します。

```bash
npm run build
# dist/ を GitHub Pages / Netlify / Cloudflare Pages 等へ
```

共有URL形式: `https://<host>/<base>/#share=v1.<payload>`

- localhost の URL は他者向け共有に使えません
- 画像・自分のメモ・学習履歴・内部IDは共有に含まれません
- 正解・解説は共有画面で除外できます

GitHub Pages でサブパス配信する場合は `vite.config.ts` の `base` を合わせてください（初期値 `./`）。

## 牌画像について

牌はアプリ内の SVG／Canvas 描画です。外部サイトから牌画像を取得しません。図形は自作の簡易表現です。
