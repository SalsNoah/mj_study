# 麻雀学習帳

スマホ優先の麻雀学習帳です。牌姿・解説・メモをブラウザの localStorage に保存し、牌の形で検索・クイズ復習できます。**ログイン・サーバー保存はありません。**

> **DECKSHOT とは無関係の独立リポジトリです。**

## 最初のコマンド

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5174 を開きます。

画像1枚の認識確認は [画像認識チェック](./ocr-check.html) へ。画像は端末内だけで処理し、独立入力した正解と比較できます。[操作・指標・検証方法](docs/OCR検証ページ.md)。

## 使い方（概要）

1. **作成**: 下部ナビ「作成」→ 牌パレットで手牌／副露／ドラ表示牌を入力 → 保存
2. **学習帳**: 文字検索と牌姿検索（色替え・反転・数字のずれ）で絞り込み。「サンプル管理」からサンプル問題を追加
3. **詳細**: 「確認した」でのみ確認回数+1。問題の編集・複製
4. **テスト**: 正解あり・出題設定ONの問題を対象に、◀▶で問題数を指定。タグなどの条件を組み合わせ可能
5. **設定**: JSONバックアップ／復元、サンプル追加、全件削除

テスト結果の「今回の誤答・不安 N問を再テスト」で、その回に回答した問題のうち、不正解または最後に保存できた理解度が「まだ不安」の問題だけを重複なく解き直せます。未回答の問題や別の回の理解度は含みません。再テストは新しい回として始まり、元の出題条件で選んだ問題を引き継ぐため、自分の回答で「最近答えていない」などの条件から外れても対象です。削除・内容変更・正解なし・出題設定OFFになった問題は除外し、実際に出題できる件数を表示します。理解度の保存に失敗した場合はその旨を表示し、今回の評価を変更しません。

問題の作成・編集と教材のタイトル・URL・コメントに未保存の変更がある場合、アプリ内の画面移動と戻る・進むでは「この画面に残る」「保存せずに移動」「保存して移動」を選べます。再読込・タブを閉じる操作ではブラウザ標準の確認を使います。元の値に戻した場合や保存後は確認しません。教材の「保存して移動」は学習回数を増やしません。

画面を変えないクエリ・フラグメントだけの更新は入力を保つため確認しません。旧問題共有URLは終了案内を表示します。アドレス欄などでハッシュを直接書き換える操作は、React Routerが履歴の移動量を取得できず保護できない場合があります。アドレス欄でURLを変える前に編集内容を保存してください。

## 打牌別の受け入れと残枚数

作成・詳細・テスト回答後の「受入れ」で、各牌を切った後のシャンテン、進む牌の種類と残枚数を確認できます。通常形・七対子・国士を対象にした四麻34種の計算です。13枚相当では現在の受け入れを表示します。打牌候補は打牌後シャンテンが最小の候補だけを受入れ枚数順に最大3件、折りたたまずに表示し、「その他の候補を表示」で残りを確認できます。詳細・テスト回答後では「受入れ」タブ内に表示します。各候補のシャンテンも確認してください。

作成では「全消去」の右にある「残枚数」を押し、萬子・筒子・索子・字牌から牌を選んで共通の入力欄で0〜自動計算の上限まで変更できます。赤五と通常五は合算し、全打牌候補の合計を更新します。詳細・テスト回答後も「残枚数」ボタンから調整できます。調整は画面内だけで、牌姿等の変更や画面移動で自動に戻ります。保存には含まれません。

数値は入力済みの手牌・副露・ドラ表示牌を除いた上限で、実際の山残数、役・フリテン、最善打牌の判定ではありません。テスト回答前には表示しません。

手牌・鳴き・ドラ表示牌を合わせて同じ牌が5枚以上にならないよう、追加できない牌は入力段階で無効化します。赤五は通常五と合算し、鳴きは組全体の枚数で確認します。読み取り結果の修正でも同じ上限を使い、不正な既存入力は自動で消さず修正できるように表示します。

仕様は [受け入れ設計](docs/受け入れ設計.md)、[残枚数調整設計](docs/残枚数調整設計.md)、[入力上限](docs/牌枚数上限修正.md) を参照してください。説明を省いた表示と残枚数ボタンの変更・最新の検証結果は [受入れUI整理](docs/受入れUI整理.md) に記載しています。

スマホ向けのタブ構成・操作導線は [スマホUI整理](docs/スマホUI整理.md) を参照してください。

## ローカル保存の制約

- キー: `mahjong-study:v1`（localStorage）
- 端末・ブラウザ・プロファイルが違えば別の学習帳
- ブラウザのデータ削除で消えます。定期的に設定から JSON バックアップを取ってください
- 目安上限 4MiB（3MiB で注意表示）。画像を増やしすぎないでください

## 静的ホスト

問題データはサーバーに送りません。**アプリ本体だけ**を静的配信します。

```bash
npm run build
# dist/ を GitHub Pages / Netlify / Cloudflare Pages 等へ
```

問題のURL共有は終了しました。問題共有URLの生成・プレビュー・取込は利用できません。以前の `#share=` リンクは内容を解析せず「問題共有は終了しました」と表示し、「学習帳へ戻る」から戻れます。空・破損した旧リンクも同じ扱いで、自動保存しません。

取り込み済み・自作の問題、画像・メモ・学習履歴・教材、JSONバックアップの形式はそのまま使えます。記録帳の「Xに記録を投稿」と設定の「製作者のX」は引き続き利用できます。

GitHub Pages でサブパス配信する場合は `vite.config.ts` の `base` を合わせてください（初期値 `./`）。

## 牌画像について

牌はアプリ内の SVG／Canvas 描画です。外部サイトから牌画像を取得しません。図形は自作の簡易表現です。

## 補完仕様（実装判断）

仕様書 §2 の補完方針に従いました。認証追加・IndexedDB 化・共有範囲の拡大は行っていません。

### サンプル問題の更新

学習帳の「サンプル管理」から、正解あり8題・正解なし2題を「サンプル」タグ付きで追加できます。画面移動はなく、検索・並べ替え・正解の表示状態を保ったまま開閉できます。設定 → データ管理 → サンプル問題からも同じ操作ができます。追加済みの問題は重複させず、足りない問題だけ追加します。旧サンプルと全内容が一致する候補は、タイトルと件数を確認して「旧候補をまとめて選択」で一括選択できます。削除するものだけ選択してください。選ばない問題や編集した問題は残ります。更新前のデータはブラウザ内に保存され、同じ欄でJSON取得・問題の復元ができます。旧サンプル全体の自動置換は行いません。

旧サンプル03（2026-10-05.3）だけは、既知の配布元情報・全内容・参照状態を確認できる未編集の問題を、読み込み時に一覧から削除します。削除前の完全なバックアップを保存・読戻しできた場合だけ削除し、学習状態・過去回答・日次記録は元のIDのまま残します。編集済み・判別不能の問題と他の9題は変更しません。サンプル管理で元の問題を復元でき、復元後は自動で再削除しません。改訂版03（2索正解）は「サンプル1題を追加」から追加でき、旧問題を編集・復元して保持している間は重複追加しません。旧JSONの取り込みでも本人編集を保護し、未編集旧03は次の読み込み時に同じ削除前バックアップを作成します。

「サンプルN題を一括削除」では、配布元を確認できる未編集の問題だけを、件数とタイトルの確認後に取り除きます。自作・編集済み問題、学習履歴・教材記録は残ります。削除前の保存・読戻しが失敗した場合は何も変更しません。復元時に後から編集・学習した同じ問題があれば、そのコピーも保持して件数を表示します。履歴の所属や重複を安全に判別できないバックアップ結合・復元は、元データを変更せず中止します。

牌姿はすべて一続きの手牌として表示します。旧保存形式の `drawn` は読み込み・バックアップの互換性のため保持し、表示・選択では別枠にしません。

旧形式を編集して手牌に統合・理牌しても、牌の種類・赤牌・枚数が同じなら内容変更とは扱いません。タイトル・タグ・私用メモだけの編集では理解度と学習履歴を保持し、牌や解説などの内容を変更した場合は従来どおり理解度を未評価に戻します。

### 画像と学習記録

画像は「問題画像」「解説画像」の各欄から直接追加できます。問題画像は回答前から表示され、追加後も用途を移せます。既存画像は解説用のままです。画像を押すと拡大し、元の大きさでも確認できます。画像はJSONバックアップに含まれます。

記録帳は日別14日、月曜始まりの週別12週、月別12か月のテスト・確認・教材の累計回数を、それぞれ独立した折れ線と数値一覧で表示します。表示期間より前の有効な記録も含み、各日・週・月の末日時点（最後は今日まで）の累計を示します。学習のない期間は横ばいとなり、日・週・月を切り替えても今日までの累計は同じです。称号の条件・正答率・保存する履歴は変えません。

「タグ別の学習状況」は、現在のタグ所属・現在の問題内容での自動判定の回答から、正解回数 ÷ 回答回数で正答率を計算します（問題ごとの正答率の平均ではありません）。自己評価のみ・旧内容・削除やサンプル管理で取り除いた問題の履歴は対象外で、回答がなければ「—（回答なし）」です。出題設定をOFFにしても、現在の内容に一致する回答は残ります。現在の「理解できた・まだ不安・未評価」の問題数は別に表示し、正解なしのメモや学習状態のない未評価問題も含みます。複数タグの問題・回答は各タグで重複して数えます。タグ名の変更・付け替えは現在の所属に従い、タグがない問題と参照先の分からないタグは分けて表示します。この表示は履歴・バックアップ・日別累計・称号・共有内容を書き換えません。


### 学習教材

保存データのない新規ブラウザでは、上達に役立つ麻雀コンテンツ７選・5分でできる牌譜検討のやり方・座学のし過ぎで打数少ない系天鳳位の座学講座の3本をこの順で表示します。既存データへの自動追加はせず、全件削除後やバックアップ置換後も補充しません。初期表示だけでは保存や学習記録を作らず、通常の保存操作で教材も保存されます。ブラウザのサイトデータ自体を消した場合は新規利用として扱います。

下段の「学習教材」からYouTube・noteなどのHTTP(S)リンクを登録し、タイトルやコメントを保存できます。教材は新しいタブで開きます。登録・リンクを開く・コメントだけの保存では学習回数は増えず、「学習した」を押した時に日時・教材名・URL・コメントを記録します。直前の記録は取り消せます。

教材ごとの回数と記録帳の日・週・月の教材系列は、同じ学習イベントから計算します。教材の履歴や称号は問題のテスト・確認・正答率に加算しません。教材の称号は手動学習記録0/1/5/10/30/100回を基準に現在の記録から算出し、取消にも追従します。問題側の称号条件は従来どおりです。

教材の詳細で「教材をアーカイブ」を選ぶと、タイトル・件数の確認後に学習中の一覧から移せます。未保存のタイトル・URL・コメントは先に保存するか元の値に戻してください。アーカイブしても教材・コメント・学習履歴は残り、学習回数・グラフ・称号は変わりません。一覧の「アーカイブ」から履歴を確認し、「学習中に復元する」で戻せます。アーカイブ中は新しい学習記録を追加できません。同じURLはアーカイブ中でも再登録せず、既存の教材を復元してください。

教材と学習イベントもJSONバックアップに含まれます。既存のバックアップも読み込めます。同じURLの重複登録を防ぎ、バックアップを繰り返し追加しても同じ教材学習イベントを二重計上しません。URLの内容取得や動画ダウンロード、視聴完了の自動判定は行いません。

アーカイブ状態もバックアップに含みます。「追加」では同じ教材の手元の内容・アーカイブ状態を保ち、新しい教材の状態はバックアップに従います。「置換」ではバックアップの状態を使い、アーカイブ日時のない旧バックアップの教材は学習中として読み込みます。

## テーマ

設定からノーマル・クール・キュート・DOPA・MOEを選べます。クールとキュートはそれぞれ専用の生成画像を全体と学習帳カードの背景に使います。DOPAは虹色の枠と光がゆっくり流れるテーマです。端末の「動きを減らす」設定では虹色を静止表示にします。MOEはアニメ調のメイドとハート・リボンの生成背景を使い、未公開のドラ裏5枚にそれぞれ異なる顔を表示します。背景のハートは2層だけがゆっくり上下し、文字・牌・操作部分は動きません。動きを減らす設定では静止し、ページが非表示の間は装飾アニメーションを一時停止します。テーマはこのブラウザだけに保存され、問題や学習履歴は変わりません。
